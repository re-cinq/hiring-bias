The Control

THE ASSUMPTION UNDER TEST

That a score delta means something. Every number in this study is a difference against an untouched résumé: change the name, watch the score move. What no part of the study has established is how far the score moves when the change means nothing. Without that floor, "this model shifts by 0.29 when the name changes" is a measurement with no unit.

The idea is not ours. u/hex4def6 proposed it in the thread under the first article: add obviously irrelevant variables — car colour, submission day of week, the weather — and see whether they move the score too. If they do, the demographic findings are reading instability rather than prejudice. It was the sharpest untested objection to the whole project, and it went unrun for months.

HOW WE TEST IT

Step 1. Add one line of job-irrelevant metadata to the top of the résumé, in the form an applicant tracking system might attach: the day the application arrived, the weather when it did, the colour of the car on file. Nothing a screener could defend acting on.

Step 2. Do it twice per field, changing exactly one word. Tuesday against Saturday, red against silver, clear against rain. The difference between a pair is the control's analogue of swapping James for Aisha — same document, same length, one meaningless value replaced by another.

Step 3. Add one edit that changes nothing at all: a single extra blank line. Meaning identical, bytes different. This is the absolute floor, the score movement attributable to nothing whatsoever.

Step 4. Run all of it through the identical pipeline — same prompt, same eleven models, same seventeen job descriptions, same five runs per cell — so the resulting number is produced by the same instrument, with the same error bars, as every demographic figure it will be compared against.

Step 5. Read it. If the placebo floor is near zero, every demographic delta on this site is strengthened. If the floor is the same size as the demographic effects, the honest headline was never "these models are biased" but "these models are unstable, and the demographic reading was inside the noise".

The control axis is excluded from every bias aggregate on this site — the heatmap, the volcano, the index. It is a ruler, not a finding.
